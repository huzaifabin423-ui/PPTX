# Bahria Town IT Security Analysis — Presentation

A 16-slide PowerPoint presentation (16:9 widescreen) generated with Python and
the [`python-pptx`](https://python-pptx.readthedocs.io/) library for a college
cyber-security project.

| | |
|---|---|
| **Student** | Huzaifa Bin Mudassar |
| **College** | The Superior International College, Rahim Yar Khan |
| **Company** | Bahria Town Pvt. Ltd. — IT Department |
| **Duration** | April 2026 – June 2026 |

## Design

- Dark-blue background (`#1A1F3A`) with white body text and cyan (`#00D4FF`) headings
- Clean Calibri typography
- Slide number (bottom-right) and project name (bottom-left) on every slide
- Tables with a coloured header row and alternating row shading
- A 5×5 risk matrix (green / yellow / red) and a 5-step incident-response flow

## How to generate

```bash
pip install -r requirements.txt
python build_pptx.py
```

This produces **`Bahria_Town_Presentation.pptx`** in the project folder.
